## 1. 产品概述

MyObsidian 是一款参考 Obsidian 设计的 Markdown 知识库管理工具，支持笔记编辑、双向链接、知识图谱可视化、AI 辅助写作等功能。所有笔记以 `.md` 文件形式存储在本地，完全可移植。

### 核心特性

| 功能 | 说明 |
|------|------|
| Markdown 编辑 | 编辑、预览、分屏三种模式 |
| 双向链接 | 使用 `[[笔记名称]]` 语法创建笔记间链接 |
| 知识图谱 | 力导向图可视化笔记关联 |
| 思维导图 | 从标题层级自动生成思维导图 |
| AI 辅助 | 续写、扩写、语法检查、摘要、格式优化 |
| 文件存储 | 笔记以本地 `.md` 文件存储 |
| 标签系统 | 使用 `#标签` 组织笔记 |
| 导出功能 | 支持导出为 Markdown、DOCX、PDF |

## 2. 快速入门

### 2.1 安装与启动

#### 桌面版（推荐）

```bash
# 克隆项目
git clone https://github.com/zhaoliangcn/my-obsidian.git
cd my-obsidian

# 安装依赖
npm install

# 一键打包并运行
./scripts/build-and-run.sh
```

#### 开发模式

```bash
# 启动 Electron 应用（Vite 热更新 + Electron）
npm run electron:start
```

### 2.2 首次使用

1. **选择知识库目录**：首次启动时会提示选择一个本地文件夹作为知识库存储位置
2. **创建笔记**：点击左侧边栏的 `+` 按钮创建第一篇笔记
3. **编辑内容**：在编辑器中输入 Markdown 内容
4. **自动保存**：所有修改自动同步到本地文件

## 4. 知识库管理

### 4.1 知识库（Vault）概念

知识库是一个本地文件夹，所有笔记以 `.md` 文件形式存储在其中。你可以：

- 使用任何文本编辑器直接修改这些文件
- 将知识库文件夹纳入 Git 版本控制
- 通过云盘同步到不同设备

### 4.2 切换知识库

1. 点击左侧边栏的 **⚙️ 设置** 按钮
2. 在设置面板中点击 **切换知识库**
3. 选择新的文件夹作为知识库
4. 点击 **恢复上次知识库** 可快速回到上次使用的知识库

### 4.3 创建笔记

- **根目录笔记**：点击左侧边栏的 `+` 按钮
- **文件夹内笔记**：在文件夹上点击 `⋮` → **新建笔记**
- **指定位置**：在代码中可通过 `createNote(folderPath)` 指定路径

### 4.4 创建文件夹

1. 点击左侧边栏的 **📁** 按钮
2. 输入文件夹名称
3. 按 **Enter** 确认，按 **Esc** 取消

### 4.5 删除笔记/文件夹

- **删除笔记**：在文件浏览器中点击笔记右侧的 **🗑️** 按钮
- **删除文件夹**：点击文件夹的 `⋮` → **删除文件夹**（包含其中所有笔记）

## 5. 笔记编辑

### 5.1 编辑模式

| 模式 | 图标 | 说明 |
|------|------|------|
| 编辑模式 | ✏️ | 纯文本编辑器 |
| 分屏模式 | ⫿ | 左侧编辑，右侧实时预览 |
| 预览模式 | 👁️ | 纯 Markdown 渲染预览 |

点击工具栏中的模式按钮进行切换。

### 5.2 标题编辑

点击笔记标题进入编辑状态，修改后按 **Enter** 确认或点击其他地方失去焦点。

### 5.3 格式化工具栏

| 按钮 | 功能 | 插入内容 |
|------|------|----------|
| **B** | 粗体 | `**选中文本**` |
| *I* | 斜体 | `*选中文本*` |
| 🔗 | 链接 | `[选中文本](url)` |
| `</>` | 行内代码 | `` `选中文本` `` |

### 5.4 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Tab` | 插入两个空格缩进 |
| `Cmd/Ctrl + K` | 聚焦搜索框 |

### 5.5 Wiki 链接

在笔记中使用 `[[笔记名称]]` 语法创建到其他笔记的链接：

```markdown
查看 [[快速入门]] 了解更多使用技巧。
```

- 在预览模式下，点击 Wiki 链接可直接跳转到对应笔记
- 支持别名语法：`[[笔记名称|显示文本]]`

## 6. Markdown 语法支持

MyObsidian 支持完整的 GitHub Flavored Markdown (GFM) 语法：

### 6.1 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

### 6.2 文本格式

```markdown
**粗体文本**
*斜体文本*
~~删除线~~
`行内代码`
```

### 6.3 列表

```markdown
- 无序列表项 1
- 无序列表项 2
  - 子项

1. 有序列表项 1
2. 有序列表项 2
```

### 6.4 代码块

````markdown
```javascript
function hello() {
  console.log("Hello, MyObsidian!");
}
```
````

### 6.5 引用

```markdown
> 这是一段引用文字
> 可以有多行
```

### 6.6 表格

```markdown
| 列1 | 列2 | 列3 |
|-----|-----|-----|
| A   | B   | C   |
```

### 6.7 分割线

```markdown
---
```

### 6.8 标签

```markdown
这是一个 #示例 标签，可以使用 #知识管理 和 #Markdown 来组织内容。
```

标签会自动提取并显示在标签面板中。

## 7. AI 辅助写作

### 7.1 功能概览

在右侧面板切换到 **AI** 标签，可使用以下功能：

| 功能 | 说明 |
|------|------|
| 续写 | 从笔记末尾自然续写内容 |
| 扩写 | 丰富现有内容的细节和论证 |
| 语法检查 | 修正语法错误和错别字 |
| 摘要 | 提取核心要点 |
| 格式优化 | 规范排版和格式 |

### 7.2 使用步骤

1. 打开要编辑的笔记
2. 切换到右侧面板的 **AI** 标签
3. 点击所需功能按钮
4. 等待 AI 生成结果
5. 选择 **替换原文** 或 **追加到末尾** 应用结果
6. 也可点击 **复制** 按钮将结果复制到剪贴板

### 7.3 停止生成

生成过程中点击 **停止生成** 按钮可中断请求。

### 7.4 配置 AI 服务

点击 AI 面板底部的 **模型设置**，可配置：

#### 服务提供商

| 提供商 | 说明 |
|--------|------|
| Ollama | 本地部署的开源模型（推荐） |
| OpenAI | OpenAI 云端 API |

#### 配置项

| 配置项 | 说明 | 示例 |
|--------|------|------|
| API 端点 | 服务地址 | `http://localhost:11434/v1` |
| 模型名称 | 使用的模型 | `qwen2.5:7b` |
| API Key | 密钥（仅 OpenAI） | `sk-...` |
| 温度 | 创造性程度（0-2） | `0.7` |
| 最大 Token | 生成文本长度 | `2048` |

### 7.5 使用 Ollama

1. 安装 Ollama：https://ollama.com
2. 拉取模型：`ollama pull qwen2.5:7b`
3. 启动 Ollama 服务
4. 在 MyObsidian 中配置端点为 `http://localhost:11434/v1`

## 8. 知识图谱

### 8.1 功能说明

知识图谱使用力导向图可视化笔记之间的关联关系。节点代表笔记，连线代表 Wiki 链接。

### 8.2 交互操作

| 操作 | 效果 |
|------|------|
| 拖拽节点 | 移动节点位置 |
| 滚轮缩放 | 放大/缩小图谱 |
| 拖拽空白区域 | 平移视图 |
| 点击节点 | 打开对应笔记 |

### 8.3 节点颜色

- **高亮节点**：当前正在查看的笔记
- **普通节点**：其他笔记

### 8.4 使用场景

- 发现笔记之间的隐藏关联
- 导航大型知识库
- 识别孤立笔记（无连线的节点）

## 9. 思维导图

### 9.1 功能说明

思维导图根据当前笔记的标题层级（`#`、`##`、`###` 等）自动生成层级结构图。

### 9.2 交互操作

| 操作 | 效果 |
|------|------|
| 点击节点 | 展开/折叠子节点 |
| 拖拽节点 | 移动节点位置 |
| 滚轮缩放 | 放大/缩小导图 |
| 拖拽空白区域 | 平移视图 |

### 9.3 导出思维导图

点击思维导图工具栏的导出按钮，可保存为图片文件。

### 9.4 注意事项

- 思维导图基于当前打开的笔记生成
- 需要笔记中包含标题层级结构
- 导图位置自动居中显示

## 11. 标签系统

### 11.1 添加标签

在笔记内容中使用 `#标签名` 语法：

```markdown
这是一篇关于 #知识管理 和 #Markdown 的笔记。
```

### 11.2 查看标签

切换到右侧面板的 **标签** 标签，显示：

- 所有已使用的标签
- 每个标签关联的笔记数量

### 11.3 按标签筛选

点击标签可筛选笔记列表，只显示包含该标签的笔记。

### 11.4 标签命名建议

- 使用简洁的词汇
- 避免特殊字符
- 保持标签层级一致（如不使用 `#父标签/子标签`）

## 12. 文件导入与导出

### 12.1 导入 Markdown 文件

1. 点击左侧边栏文件浏览器中的 **📤** 按钮
2. 选择一个或多个 `.md` 文件
3. 文件自动导入到知识库根目录
4. 如有同名笔记，自动添加序号避免冲突

### 12.2 导出为 Markdown

在文件浏览器中点击笔记的 **⬇️** 按钮，导出为 `.md` 文件。

### 12.3 导出为 DOCX

1. 打开要导出的笔记
2. 点击编辑器工具栏的 **📄** 按钮
3. 文件自动下载为 `.docx` 格式

### 12.4 导出为 PDF

1. 打开要导出的笔记
2. 点击编辑器工具栏的 **📥** 按钮
3. 文件自动下载为 `.pdf` 格式

## 15. 常见问题

### 15.1 笔记丢失怎么办？

笔记以 `.md` 文件形式存储在你选择的知识库文件夹中。即使应用数据被清除，只要文件夹还在，重新选择该文件夹即可恢复所有笔记。

### 15.2 如何备份知识库？

直接复制知识库文件夹到任意位置即可。你也可以使用 Git 进行版本控制：

```bash
cd /path/to/vault
git init
git add .
git commit -m "Initial commit"
```

### 15.3 AI 功能无法使用？

检查以下事项：

1. Ollama 服务是否正常运行：`ollama list`
2. 模型是否已下载：`ollama pull qwen2.5:7b`
3. API 端点配置是否正确
4. 网络连接是否正常

### 15.4 如何迁移到其他设备？

1. 复制整个知识库文件夹到新设备
2. 安装 MyObsidian
3. 首次启动时选择该文件夹作为知识库

### 15.5 支持哪些平台？

- **macOS**：完整支持
- **Windows**：支持（需重新打包）
- **Linux**：支持（需重新打包）
- **浏览器**：部分功能受限（需要 File System Access API 支持）

### 15.6 如何更新应用？

```bash
git pull origin main
npm install
./scripts/build-and-run.sh
```

### 15.7 笔记文件存储在哪里？

笔记文件存储在你首次启动时选择的知识库文件夹中，以 `.md` 格式保存，可直接用任何文本编辑器打开编辑。
